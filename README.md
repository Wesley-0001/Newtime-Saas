# New Time

Plataforma web para gestão de pessoas, processos e evolução profissional em ambientes produtivos.

---

## ✨ Visão Geral

O New Time é um sistema focado em organização de equipes, acompanhamento de desenvolvimento profissional e apoio à tomada de decisão em operações industriais.

A plataforma reúne, em um único ambiente, recursos para gestão de colaboradores, acompanhamento de indicadores e estruturação de processos internos.

---

## ⚙️ Funcionalidades

- Gestão de colaboradores e estrutura organizacional  
- Acompanhamento de evolução e desempenho  
- Controle de frequência e registros operacionais  
- Visualização de indicadores e informações consolidadas  
- Interface adaptada para diferentes perfis de acesso  

---

## 💻 Tecnologias

- HTML, CSS e JavaScript  
- Firebase (Firestore & Storage)  

---

## 🚀 Acesso

O sistema é executado diretamente no navegador e pode ser hospedado em ambientes estáticos.
